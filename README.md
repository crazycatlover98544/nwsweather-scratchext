# NWSWeather Scratch Extension
NWSWeather, or "Weather" for short, is a simple Scratch extension (for mods like TurboWarp) that gets the weather nearby you for the current date using the National Weather Service (weather.gov).  
**I do not guarentee that this will work outside of the U.S..**  
This extension is designed run sandboxed. As stated in the MIT license, I am not responsible for anything that happens if you do not do this.  

This extension uses the following URLS to request weather data:

- https://free.freeipapi.com/api/
- https://api.weather.gov/

The function to request a response from a website was adapted from https://extensions.turbowarp.org/fetch.js, by GarboMuffin. For more information about this, open up the code file.
